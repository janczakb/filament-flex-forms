The **Voice note recorder** (`voice_note`) captures short spoken answers in the browser and stores them as uploads — ideal for support notes, accessibility, and mobile-first surveys.

## Configuration

<Steps>
  <Step title="Add the block">
    Drag **Voice note recorder** from the Media category onto the canvas.
  </Step>
  <Step title="Set limits">
    Configure max duration / size and accepted formats in field settings so recordings stay within your storage budget.
  </Step>
  <Step title="Review in Submissions">
    Open Submissions to play recordings inline. Voice notes use an audio player in the inbox, not a static file icon.
  </Step>
</Steps>

<Callout type="warning">
  Recording requires microphone permission in the respondent’s browser. Always provide a text alternative (or make the field optional) for accessibility.
</Callout>
