The **Name** block (`name`) is a Studio composite for person names. Fill renders the configured parts as text inputs; submissions store structured name parts for Contacts and CRM mapping.

## Configuration

<Steps>
  <Step title="Add Name">
    Drag **Name** from the Text category (it leads the text catalog).
  </Step>
  <Step title="Parts">
    Toggle **Last name**, optional **Middle name**, labels, and whether last name is required.
  </Step>
</Steps>

Prefer Name over separate Text inputs when you want consistent Contacts identity and CRM first/last mapping.
