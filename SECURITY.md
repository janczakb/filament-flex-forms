# Security Policy

## Supported Versions

The following versions of Flex Forms are currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

**Do not** open a public GitHub issue for security vulnerabilities.

Send a **private** report to **[barek122@gmail.com](mailto:barek122@gmail.com?subject=Flex%20Forms%20security)** with the subject line `Flex Forms security`.

Include: Flex Forms version, Laravel/PHP/Filament versions, impact summary, reproduction steps, and a way to contact you.

Full disclosure process (what to include, timelines, scope):  
**https://flexforms.bjanczak.com/resources/support#report-a-security-vulnerability**

We acknowledge valid reports and coordinate a fix and disclosure timeline with the reporter.
