**PulseFit Plan** is a logic recipe for BetterMe-style funnels: gender → goal → path → contact, with **Branch** (eq per answer) and **auto-jump** so choosing an option advances the page immediately.

## What you get

- Choice cards with **Branch → Go to page** on every step (including leaf focus questions)
- Separate male / female goal and focus pages that merge into one contact step
- Form setting **auto_jump** enabled
- Progress bar that follows the **visited path** (other branch pages stay hidden in tiles mode)

## How to build it

1. **Create form** with a blank canvas, then add choice pages in Studio
2. On each choice field, use **Branch** (or Workflow → Rules) to jump per answer — avoid *Is not empty* shortcuts if you want Branch chrome
3. Enable **auto_jump** in form settings so answering advances without Next
4. Preview fill (or embed) — answering should advance without tapping Next
