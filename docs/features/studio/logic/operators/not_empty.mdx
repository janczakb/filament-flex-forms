**Is not empty** checks that a field **has an answer** — any text, selection, upload, signature, or numeric value counts as filled.

Use it to reveal follow-ups once they start typing, gate routing on “attachment provided”, or require downstream logic only after a prerequisite field is completed.

---

## When to choose this

| Goal | Use **Is not empty** | Use something else instead |
|------|---------------------|----------------------------|
| Any answer provided | ✓ | — |
| Still blank | ✗ | **[Is empty](/features/studio/logic/operators/empty)** |
| Specific value | ✗ | **[Equals](/features/studio/logic/operators/eq)** or comparisons |
| Text contains snippet | ✗ | **[Contains](/features/studio/logic/operators/contains)** |
| Yes/no checked | ✗ | **[Equals](/features/studio/logic/operators/eq)** on toggle |

---

## Exact behavior

Filled means **not** any of:

- `null`
- `""`
- `[]`

Whitespace-only text (`"   "`) is **not** empty — it counts as an answer.

No comparison value required.

For signatures, Studio may show **Is signed** — same as **Is not empty** for that block type.

## Blank / unanswered answers

**Does not match** when empty — this operator is the inverse of [Is empty](/features/studio/logic/operators/empty).

## Worked examples

### Reveal details after company name

> **When** Company **is not empty** → **Then** [Show blocks](/features/studio/logic/actions/show-blocks) `VAT ID, Billing address`

### Attachment triggers review page

> **When** Supporting document **is not empty** → **Then** [Jump to page](/features/studio/logic/actions/jump-to-page) `Document review`

### Signed waiver enables submit

> **When** Waiver **is signed** → **Then** allow submit (remove [Hide submit](/features/studio/logic/actions/hide-submit) paired rule)

Often paired: **Is not signed → Hide submit**.

### Any date picked for scheduling

> **When** Preferred date **is not empty** → **Then** [Show blocks](/features/studio/logic/actions/show-blocks) `Time slot`

Use **Equals** / comparisons for specific dates.

## Common mistakes

- Using **Is not empty** when you need a specific value — add **Equals** or **Contains**.
- Using on toggle — unchecked may still be a valid “No” answer; use **Equals**.
- Assuming spaces are empty — `" "` is not empty.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Rule fires too early">
    **Is not empty** triggers on any input — combine with **Contains** or length checks via calculated field if needed.
  </Accordion>
  <Accordion title="File uploaded but rule off">
    Upload may still be processing — retry after upload completes on Fill.
  </Accordion>
  <Accordion title="vs Is empty pair">
    Ensure **Show** and **Hide** rules do not fight — check evaluation order.
  </Accordion>
  <Accordion title="Default pre-filled value">
    Field may start “not empty” — adjust defaults in block settings.
  </Accordion>
</AccordionGroup>
