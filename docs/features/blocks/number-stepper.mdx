The **Number stepper** (`number_stepper`) is a dedicated quantity control with `+` / `-` buttons. Use it for order counts and inventory-style inputs. For a plain numeric field without steppers, prefer [Number](/features/blocks/number) (`integer`).

## Configuration

Set min, max, step, and optional icons for the increment/decrement buttons.
