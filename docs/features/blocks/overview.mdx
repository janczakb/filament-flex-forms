Blocks are the fields and content pieces you drag onto the Studio canvas. Flex Forms builds on Filament Flex Fields so every block is responsive, configurable, and export-ready.

CAPTCHA is **not** a canvas block — configure one provider under [Form Settings → Access](/features/settings/access).

## Field settings

Click a block on the canvas to open **field settings** in the **left** dock (replacing the component catalog). Set the internal **Name**, public **Label**, validation, and type-specific options. See [Field settings](/features/studio/field-settings).

## Best practices

<AccordionGroup>
  <Accordion title="Pick the most specific block">
    Use Phone for phones, Currency for money, Email for emails — not generic Text input.
  </Accordion>
  <Accordion title="Name vs label">
    Integrations and query prefills use the internal **Name**, not the visible label. See [Name & label](/get-started/name-label-fields).
  </Accordion>
</AccordionGroup>
