The **Flex slider** (`flex_slider`) is a branded pill rail with a capsule thumb. Enable **Range (two handles)** when respondents should pick a min–max band (budget, age range, quantity band).

## Configuration

<Steps>
  <Step title="Add the block">
    Drag **Flex slider** from the Number category onto the canvas.
  </Step>
  <Step title="Tune the rail">
    Set min, max, step, size, step dots, track fill, and value placement in field settings.
  </Step>
  <Step title="Optional range mode">
    Turn on **Range (two handles)** for a pair of values instead of a single number.
  </Step>
</Steps>
