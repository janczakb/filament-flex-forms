---
title: "Is not between"
description: "When clause operator: The number or date falls outside an inclusive min–max range."
icon: "arrows-left-right"
keywords: ["logic", "operator", "not_between", "range", "when"]
---

**Is not between** matches when the answer is **outside** an inclusive range — strictly below **Min** or strictly above **Max**.

Blank answers never match (fail-closed). Incomplete ranges never match.

## Which field types

| Family | Available |
|--------|-----------|
| Number | ✓ |
| Date & time | ✓ |
