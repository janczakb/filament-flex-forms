icon: "calendar"
keywords: ["logic", "operator", "date_after_relative", "relative", "when"]
---

**Is after (relative)** compares a date answer to a rolling anchor (`today`, `+7d`, `-1d`, `+2w`, …).

Blank answers and invalid anchors never match.
