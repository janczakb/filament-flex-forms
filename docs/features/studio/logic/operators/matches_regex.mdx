**Matches regex** checks whether a text answer matches your pattern (PCRE).

Use it for structured codes, custom ID formats, and advanced text gates that simple Starts with / Contains cannot express.

---

## Exact behavior

- **Text fields only.**
- Pattern max length **200**; subject is capped at **10 000** characters.
- Invalid patterns never match (fail-closed).
- Blank answers never match.
- Patterns may be written with or without delimiters (`^[A-Z]{3}$` or `/^[A-Z]{3}$/`).
