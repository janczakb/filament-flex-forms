**Is between** matches when the answer is **inside** an inclusive range — at or above **Min** and at or below **Max**.

Use it for age bands, score brackets, and date windows (e.g. stay dates inside a season).

---

## Exact behavior

- **Numbers** and **dates** only.
- Range is inclusive on both ends.
- Value shape: `[min, max]` or `{ min, max }` (Studio uses two value fields).
- Blank answers never match. Incomplete ranges (missing min or max) never match.
