The **Plain text** block (`plain_text`) is **content**, not an answer. Use it for instructions, legal blurbs, and section intros between questions.

Respondents cannot type into it. For answerable formatted text, use [Rich text](/features/blocks/rich-text).

## Configuration

Edit the body copy in field settings. Place Plain text blocks between question blocks on the canvas.
