title: "Does not match regex"

icon: "code"
keywords: ["logic", "operator", "regex", "not_matches_regex", "when"]
---

**Does not match regex** matches when a text answer **fails** your pattern.

Blank answers never match. Invalid patterns never match (fail-closed).
