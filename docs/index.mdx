## Why teams choose Flex Forms

<CardGroup cols={2}>
  <Card title="Studio that ships production forms" icon="pencil-ruler" href="/features/studio/overview">
    Drag-and-drop canvas, multi-page flows, Logic Board, calculated fields, Design + custom CSS — then **Publish** a live schema operators can trust.
  </Card>
  <Card title="Lean public fill" icon="smartphone" href="/features/forms/fill-link">
    Dedicated fill & embed runtime — not your Filament panel JS. Access gates, CAPTCHA, partials, and embeds served from **your** app.
  </Card>
  <Card title="Data you already own" icon="database" href="/features/submissions/overview">
    Submissions and Contacts live in Laravel. Optional answer encryption, retention controls, CSV / Excel export — no SaaS silo.
  </Card>
  <Card title="Insights under real traffic" icon="chart-column" href="/features/insights/overview">
    Visits, starts, completes, drop-offs. Beacon → today buffer → rollups; optional Redis when unique counts get heavy.
  </Card>
  <Card title="Integrations built for ops" icon="plug" href="/integrations/overview">
    Save the submission first, deliver CRM / ESP / Slack **async**. Named Connections, delivery ledger + Replay, circuit breaker, hardened outbound HTTP.
  </Card>
  <Card title="Payments in the same product" icon="credit-card" href="/features/transactions/overview">
    Stripe Payment block and a Transactions hub — not a bolted-on third party form tool.
  </Card>
  <Card title="Extensible like first-party" icon="code" href="/developers/custom-integrations">
    Custom drivers reuse FieldMapper, Connections, ledger, and the same reliability stack as HubSpot or Slack.
  </Card>
  <Card title="Same design system as Flex Fields" icon="blocks" href="/features/blocks/overview">
    Forty-plus Studio blocks on the Flex Fields component family — consistent UI in Studio and classic Filament forms.
  </Card>
</CardGroup>
