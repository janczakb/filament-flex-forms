A global dashboard is useful, but the real power of Insights lies in segmentation. Filters let you isolate specific cohorts of traffic to see how different demographics behave.

## Date ranges

Every Insights tab is scoped to the active date range in the toolbar.

<Steps>
  <Step title="Quick presets">
    Pick common ranges such as **Today** or **Last 7 days**.
  </Step>
  <Step title="Custom campaigns">
    Choose **Custom range**, then set the start and end dates in the date range control. The calendar opens in a popover so the toolbar does not push the layout down.
  </Step>
</Steps>

---

## Cohort filters (Visits, Drop-offs & Global Stats)

On form **Insights** (**Visits** / **Drop-offs**) and workspace **Global Stats**, open **Filters** next to the date range (same control pattern as Contacts). A panel slides in from the right with the traffic dimensions for the current range.

<CardGroup cols={2}>
  <Card title="Demographic slicing" icon="users-viewfinder">
    Filter by **Device**, **Country**, **City**, **Browser**, or **OS**. *Example: Are mobile users dropping off faster than desktop?*
  </Card>
  <Card title="Attribution" icon="bullseye">
    Filter by **Referrer** or `utm_source` / `utm_medium` / `utm_campaign`. *Example: Which campaign converts better?*
  </Card>
</CardGroup>

Active filters appear as chips under the toolbar so you can clear one dimension at a time, or clear all from the drawer footer.

## Export & share

From the Insights header (before **Edit**):

- **Export events CSV** — download raw events for the current range and filters
- **Share insights** — create password-optional public dashboard links
